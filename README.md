# 🎵 Music Streaming Website

A simple and interactive **Music Streaming Website** developed using HTML, CSS, JavaScript, PHP, and MySQL.

The project provides a web-based music platform with an interactive music library and user authentication features. It demonstrates the integration of frontend technologies with a PHP and MySQL backend.

## 📌 Project Overview

The Music Streaming Website is a web application developed to provide users with an interactive interface for accessing and exploring music.

The project includes a homepage, user login and registration pages, a dashboard, JavaScript-based interactions, and PHP/MySQL database connectivity.

This project was developed as a practical implementation of web development concepts including frontend design, JavaScript functionality, backend development, and database integration.

## 🚀 How to Run the Project

Follow the steps below to run the project on your local system.

### Prerequisites

Make sure the following are installed on your computer:

- XAMPP
- Web Browser
- Git (optional)

### 1. Clone the Repository

Open Command Prompt or Git Bash and run:

`git clone https://github.com/Thalanki-Jahnavi/Music-Streaming-Website.git`

Or download the repository as a ZIP file from GitHub and extract it.

### 2. Move the Project to XAMPP

Copy the `Music-Streaming-Website` folder into the XAMPP `htdocs` directory.

The folder should be located at:

`C:\xampp\htdocs\Music-Streaming-Website\`

### 3. Start XAMPP

Open the XAMPP Control Panel.

Start the following services:

- Apache
- MySQL

Make sure both services are running.

### 4. Create the Database

Open your web browser and go to:

`http://localhost/phpmyadmin`

Create a new database for the project.

Then select the database and click **Import**.

Choose the `database.sql` file from the project folder and click **Go**.

### 5. Configure Database Connection

Open `db_connect.php` and check the database connection details.

Update the database name, username, and password according to your local MySQL configuration.

Example:

`$servername = "localhost";`

`$username = "root";`

`$password = "";`

`$database = "music_streaming";`

If the project uses `connect.php`, make sure the database details in that file are also correct.

### 6. Run the Project

Open your web browser and enter:

`http://localhost/Music-Streaming-Website/`

The Music Streaming Website should now open in your browser.
